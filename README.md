# snehal-vs.github.io

Source for my personal portfolio site, published with GitHub Pages at
**https://snehal-vs.github.io/**.

A clean, single-page site covering my current role, publications, mentorship,
and interests. Built with plain HTML and CSS — no build step or dependencies.

## Structure

```
index.html         Page content
css/style.css      Styles (light/dark, responsive)
assets/            Images (portrait, etc.)
serve.ps1          Small local preview server
```

## Preview locally

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Then open http://localhost:8000/ (Ctrl+C to stop).
